# 视频拉片 · 镜头检测抽帧小程序

一个超简单的本地桌面小工具：选择视频 → 自动检测镜头边界 → 按镜头抽取代表帧图，保存到你指定的位置。

- 集成 [PySceneDetect](https://github.com/Breakthrough/PySceneDetect)（Python API，进程内调用，不走命令行）
- 纯本地运行，视频不上传，无需联网
- 检测器：ContentDetector（实测最准），支持灵敏度（阈值）调节

## 功能

| 能力 | 说明 |
| --- | --- |
| 镜头检测 | ContentDetector 自动切分镜头边界，输出镜头清单 |
| 按镜头抽帧 | 每个镜头抽取 N 张代表帧（默认 2 张/镜头），文件以「视频名_时间点」命名，如 `test_video_00;00;02.400.jpg`（时间点为该帧在视频中的精确时刻） |
| 灵敏度可调 | 阈值 5–60（默认 8），越小越敏感、检出更多切点 |
| 可视化界面 | 选视频、选保存位置、调参数、实时日志 |


## 使用

1. 「选择视频」：选择要分析的视频（支持 mp4/mkv/avi/mov/flv/wmv/ts/m4v/webm）
2. 「帧图保存到」：选择输出目录（留空则自动保存到视频同目录的 `拉片帧图-<视频名>` 文件夹）
3. 「灵敏度」：ContentDetector 阈值，默认 8。越小越敏感（检出更多切点，也可能误报）；越大越钝
4. 「每镜头抽帧数」：每个镜头保存的代表帧数量，默认 2
5. 点「开始分析」，日志区实时显示镜头数和保存结果

抽出的帧图以视频时间点命名（`视频名_时;分;秒.毫秒.jpg`，如 `test_video_00;00;02.400.jpg`），文件名即帧在视频中的精确位置，方便对照时间轴。

## 常见问题

**Q：提示无法打开/解码视频？**
A：H.264 编码的 MP4 开箱即用。RMVB / HEVC / MKV 等格式需要 ffmpeg，安装后（`winget install ffmpeg` 或下载便携版加入 PATH）即可支持；检测和抽帧的更多格式兼容也会随之增强。

**Q：镜头切得不准怎么办？**
A：主要调「灵敏度」。硬切多的素材可降到 5–10；运镜/渐变多的素材适当调高（15–30）。可以先跑一遍看镜头数是否接近预期，再微调。

**Q：只想命令行用？**
A：激活 `.venv` 后：
```
.venv\Scripts\python -c "import sys; sys.path.insert(0,'.'); import app; app.analyze_video('视频.mp4', '', 2, 8, print)"
```

## 说明

- 检测原理为帧间内容差异打分（启发式算法），对快速硬切准确度高，对渐变/同场景大运动存在固有局限。
- 本项目由本地工作流整理发布，测试基准：6 段硬切测试视频，阈值 8 全镜头命中。
