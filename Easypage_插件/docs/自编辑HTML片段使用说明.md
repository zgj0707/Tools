# 把易页编辑器嵌入自己的 HTML

这个构建会把当前插件工具条、页面编辑、文字格式、撤销/重做、源码局部写回和原件恢复点打成一个内联脚本。HTML 不需要再加载 EasyPage 扩展，也不需要额外的 CSS 或 JavaScript 文件。

## 生成代码块

在项目目录运行：

```powershell
npm run build:embed
```

生成的 `dist-embed/easypage-self-editor-snippet.html` 是完整代码块。将它全部复制到目标 HTML 的 `</body>` 前：

```html
  <!-- 其他页面内容 -->
  <script data-easypage-self-editor="1">/* 生成的完整编辑器代码 */</script>
</body>
```

不要手工删掉 `data-easypage-self-editor="1"`：保存器用它识别并保留编辑器，同时不把它算作页面业务脚本警告。

## 在 Chrome 中使用

1. 将 HTML 保存到本地，然后在 Chrome 里直接打开这份文件（地址以 `file://` 开头）。
2. 使用“编辑模式”选择页面元素；双击文本可改字。工具条上的格式按钮和撤销/重做沿用插件现有行为。
3. 每次点击“覆盖原件”都需要确认。首次保存时，在 Chrome 文件选择框中选择这份原件；之后浏览器会尝试复用已授权的文件句柄，但每次仍会弹出覆盖确认。确认后会先把原文件字节存进本机恢复点，再局部写回源码。若 Chrome 先要求单独授予写权限，按提示再点一次保存即可，刚选中的文件会在当前标签页内保留。

Chrome 不向页面脚本提供已选文件的完整路径。首次选择时请核对选择的是当前 HTML 原件；工具条会给出当前页面来源路径作为核对信息。取消确认不会写入。

## 适用边界

- 嵌入代码能编辑通过浏览器打开的 HTML 页面，但覆盖保存仅对直接打开的本地 `file://` 页面启用。部署在网站上的 HTML 不能由浏览器页面脚本直接覆盖服务器文件。
- 页面若用内容安全策略（CSP）禁止内联脚本，Chrome 会阻止嵌入片段运行。
- 保存从原文件源码生成局部补丁：文字和属性变更只替换对应源码区间，未改动部分逐字节保留。加粗等操作新增/移除行内标签时，能精确对应原始纯文本的会只插入或移除标签；文本含实体或换行规范化等无法直接映射时，才重写最小受影响元素的内容区。
- 源码与编辑器加载时的页面结构不一致、脚本/样式原始文本被运行时改写、结构变更范围过大、恢复点写入失败或编码无法保真时，保存会停止，不会退回整页序列化。
- 目前支持安全保留 UTF-8、UTF-16 和 Windows-1252 编码；其他编码会阻止覆盖，避免中文变乱码。Windows-1252 文件若编辑内容含该编码无法表示的字符，也会阻止覆盖。HTML 排版和换行在未触碰区域保持原样；真正修改过的属性或必须重写的最小元素内容可能局部调整。
- 每次成功覆盖前，当前文件的原始字节会存入浏览器本机 IndexedDB。工具条“恢复备份”按钮可将最近一次保存前的版本精确写回，并重新载入页面。
- 页面中有业务脚本时，脚本可能造成动态内容变化；无法可靠映射回原源码的情况会阻止覆盖。外部程序在保存确认期间修改原文件时，也会被检测并阻止覆盖。
- HTML 和编辑器代码保存在同一文件里，因此代码块无需单独托管。页面引用的图片、样式、脚本等其他资源仍按原页面的引用方式加载。

当前生成的完整自包含片段约 200 KB（gzip 约 64 KB），其中包含用于读取 HTML 源码位置的解析器。

## 构建入口

- `vite.embed.config.ts`：单 IIFE 构建，内联 CSS，无代码分块。
- `scripts/package-embed-snippet.mjs`：把 IIFE 安全包装成 HTML `<script>` 片段，避免 JS 内容中的 `</script` 提前截断 HTML。
