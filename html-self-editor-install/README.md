# HTML 自编辑插件安装 Skill

给任意本地 HTML 文件一键装上「自编辑插件」，让它在浏览器里能直接改内容、保存回原文件。适合经常要改 HTML 文档、又不想开编辑器的人。

## 功能

装完插件后，用 Chrome 打开目标 HTML 文件，右上角会出现一个浮动工具栏：

| 按钮 | 作用 |
|------|------|
| ≡ 抓柄 | 按住拖动工具栏到任意位置，避免遮挡内容 |
| 编辑模式 / 完成编辑 | 开关编辑状态，进入后可选中文字直接改 |
| **B** | 加粗选中文字（Ctrl+B） |
| *I* | 斜体（Ctrl+I） |
| <u>U</u> | 下划线（Ctrl+U） |
| 保存 | 把改动写回原文件（Ctrl+S） |

核心能力：
- **工具栏可拖动**：按住左侧「≡」抓柄（或工具条空白处）拖到任意位置，不再挡住内容。位置会自动记住，下次打开还在原位。
- **就地编辑**：进入编辑模式后，页面文字可直接点选修改，所见即所得。
- **保存回原文件**：Ctrl+S 或点「保存」，改动直接写回你打开的那个 HTML 文件，不用另存。
- **记住文件**：第一次保存时选一次文件，之后自动记住，再保存不再弹框。
- **零外链、自包含**：插件是一段独立脚本，不依赖任何网络资源，离线可用。

## 使用方法

### 1. 安装插件到 HTML 文件

对 AI 助手说：

> 「给这个 HTML 装自编辑插件」

把目标 HTML 文件路径给它即可。AI 会自动：
1. 把插件脚本插到文件 `</body>` 标签前
2. 如果文件里已有旧版插件，自动替换成新版（不会重复装两个）
3. 装完自动校验，确认插件装对了

### 2. 在浏览器里使用

1. 用 **Chrome 或 Edge** 打开装好插件的 HTML 文件（双击文件即可，地址栏是 `file://` 开头）
2. 右上角出现工具栏。若挡住内容，按住左侧「≡」抓柄把它拖到别处（位置会自动记住）
3. 点「编辑模式」→ 直接点选页面文字修改，或用 B / I / U 按钮调整格式
4. 点「保存」或按 **Ctrl+S**，改动写回原文件

> 提示：建议用 Chrome/Edge。插件依赖浏览器的「本地文件保存」能力，这两个浏览器支持最好。

## 常见问题

**Q1：点「保存」没反应，或提示"浏览器不支持本地文件保存"？**
用 Chrome 或 Edge 打开文件。插件依赖 File System Access API，只有这两个浏览器支持。Firefox、Safari 不支持。

**Q2：第一次保存弹了个文件选择框，正常吗？**
正常。第一次保存需要你确认要写回哪个文件（选你打开的那个 HTML 即可）。选一次后插件会记住，之后保存不再弹框。

**Q3：保存时提示"未获得写入权限，请再次 Ctrl+S 并在提示中允许"？**
浏览器安全机制。再按一次 Ctrl+S，在弹出的提示里点「允许」即可。

**Q4：在网页上（http:// 开头）打开，保存不了？**
插件只对本地文件（`file://`）生效。请把 HTML 文件下载到本地再打开。

**Q5：工具栏挡住了页面内容，怎么挪开？**
按住工具栏左侧的「≡」抓柄，拖到不碍事的位置即可。也可以按住工具条的空白处拖动。按钮本身只响应点击，不会误触拖动。

**Q6：拖走的位置会记住吗？下次打开还在原地吗？**
会记住。位置存在浏览器本地，同一个文件下次打开时工具栏会回到你放的位置。清除浏览器数据会重置回右上角（不影响文件内容）。

**Q7：会不会把原文件改坏？**
插件只在你点「保存」时才写入，平时浏览不会动文件。建议重要文件先备份一份再编辑。

**Q8：装完插件，文件变大了吗？**
会加约 8.5KB（插件脚本本身）。对正常 HTML 文件影响可忽略。

**Q9：怎么卸载插件？**
把文件里那段 `<script data-easypage-self-editor="1">...</script>` 删掉即可。插件不残留任何其他东西（拖动位置存在浏览器本地记录里，与文件无关，可忽略）。
