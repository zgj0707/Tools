# 01 · 技术基线与接口契约（实现的唯一依据）

> **状态规则**：本文件在 **T003 冻结**。冻结前不得开工 Stage 1 功能卡；冻结后任何对技术栈、目录、接口签名、常量、依赖白名单的修改，都必须由调度者评审并更新版本号，**执行者不得自行改动**。文中标注「PoC 待定」的条目，以 T002/T003 结论为准。
> 目标：让执行者**不需要做任何架构决策**，照着本文档的目录、签名、常量、命名实现即可。

---

## 1. 架构总原则（必须遵守）

1. **真实 DOM 是唯一事实源**：被编辑页面解析为一个真实 `Document`，所有编辑直接作用于其 DOM 节点；**不引入虚拟组件树**（避免 GrapesJS 式组件模型与"任意第三方 HTML"错配）。
2. **被编辑文档与编辑器外壳物理隔离**：被编辑页面渲染在独立 `<iframe>` 内；编辑器的工具栏、面板、选中框、手柄、参考线等全部在另一个外壳子树（`#ep-overlay-root`）中，**绝不是被编辑元素的子节点**。
3. **零污染引用**：编辑器引用被编辑节点一律用 `WeakMap<Element, …>` 等内存结构，**不在被编辑 DOM 上写 `id`/`data-*` 来做选中映射**。唯一例外是就地编辑期间临时加的 `contenteditable` / `data-ep-editing`，提交后立即移除，导出前再统一清理兜底。
4. **端口 + 适配器（依赖倒置）**：所有第三方库只允许出现在 `src/adapters/`；`src/core/` 只定义端口接口与纯逻辑，**不得 import 任何第三方库、不得 import `adapters/`**。由 `src/platforms/web/` 装配具体实现。
5. **一切可改变文档的操作都走命令（Command）**，统一接入撤销/重做；禁止在事件回调里直接改 DOM 而不经过命令。
6. **位移只用 `transform: translate()`，不改 `position`、不抽离文档流**；尺寸改 `width/height`。

**import 边界（ESLint 强制，T001 配置、T003 复核、2026-09-22 补全）**：

- `core/**`：禁止 import 第三方包，禁止 import `app/**`、`adapters/**`、`platforms/**`。
- `app/**`：只允许 import `core/**` 与自身；禁止 import `adapters/**`、`platforms/**`（具体实现只能由装配根注入）；禁止直接 import 第三方交互/编辑库。

- **前置条件（2026-09-22 补）**：`import/no-restricted-paths` 必须先能解析 import 目标才生效，
  因此 `.eslintrc.cjs` 必须保留 `settings['import/resolver'].node.extensions`。
  缺该配置时规则**静默失效** —— 此前 core→app/adapters 这条边界从未真正拦下过任何代码。
  验证方式：在 `src/app/` 放一个 import `../adapters/...` 的探针文件，`npx eslint` 必须报错。

## 4. 核心端口接口（TypeScript，签名逐字实现）

> 下列接口是**契约**。卡片中说"实现/依赖某端口"即指此处签名。适配器实现这些接口；core/app 只依赖接口。文件统一放 `src/core/ports/`。

```ts
// ── 会话与模型 ──────────────────────────────────────────────
export interface EditorSession {
  readonly doc: Document;            // 被编辑页面的 Document
  readonly body: HTMLElement;        // doc.body
  readonly selection: SelectionModel;
  readonly history: HistoryStack;
  readonly capabilities: CapabilityIndex;
  readonly meta: SessionMeta;        // 原始导入快照、资源清单、脏标记等
  markDirty(): void;
}

export interface SelectionModel {
  readonly elements: Element[];      // 当前选中（多选有序）
  select(els: Element[]): void;
  toggle(el: Element): void;         // Ctrl/Shift 多选
  clear(): void;
  parentOf(el: Element): Element | null; // 面包屑选父级
  onChange(cb: () => void): () => void;
}

// 可编辑性分级（见 §7）
export type Capability =
  | 'full'           // 可进入内部编辑/改样式/位移
  | 'inline-text'    // 仅可整体改文本（受限）
  | 'block-only'     // 仅可整体移动/隐藏/替换，不可进内部
  | 'non-editable';  // canvas/Shadow DOM 内部/伪元素等
export interface CapabilityIndex {
  of(el: Element): Capability;
  reasonOf(el: Element): string;     // 不可编辑时给用户的原因文案 key
}

// ── HTML 解析 / 序列化 ──────────────────────────────────────
export interface ParseResult {
  doc: Document;
  warnings: ParseWarning[];          // 容错修复提示（数量、类型）
  externalResources: ResourceRef[];  // 外链图片/字体/脚本清单
}
export interface ParseWarning { code: string; messageKey: string; count?: number }
export interface ResourceRef { tag: string; url: string; kind: 'img'|'font'|'script'|'stylesheet'|'other' }

export interface HtmlIO {
  parse(source: string): ParseResult;
  serialize(doc: Document, opts: SerializeOptions): SerializeResult;
}
export interface SerializeOptions {
  stripEditorArtifacts: boolean;     // 导出必须 true
  pretty?: boolean;
}
export interface SerializeResult {
  html: string;
      residue: EditorArtifact[];     // 清理后仍检测到的编辑器残留（应为空，非空则报错阻断导出）
}
export interface EditorArtifact { kind: string; detail: string }

// ── 命令 / 历史 ─────────────────────────────────────────────
export interface ICommand {
  readonly name: string;             // 如 'set-style'
  execute(): void;
  undo(): void;
}
export interface HistoryStack {
  push(cmd: ICommand): void;         // push 时立即 execute()
  undo(): void;
  redo(): void;
  canUndo(): boolean;
  canRedo(): boolean;
  onChange(cb: () => void): () => void;
  clear(): void;                     // 导入/重置时
}
// 内置命令（core/commands 内实现，签名供卡片使用）
export declare class SetTextCommand implements ICommand { constructor(target: Element, next: string, prev: string) }
export declare class SetStyleCommand implements ICommand { constructor(targets: Element[], props: Record<string,string>, prev: Map<Element,Record<string,string>>) }
export declare class SetAttributeCommand implements ICommand { constructor(target: Element, attr: string, next: string|null, prev: string|null) }
export declare class MoveCommand implements ICommand { constructor(targets: Element[], dx: number, dy: number) } // 写 transform: translate
export declare class ResizeCommand implements ICommand { constructor(target: Element, box: {width:number;height:number}, prev: {width:number;height:number}) }
export declare class InsertNodeCommand implements ICommand { constructor(node: Node, parent: Element, index: number) }
export declare class RemoveNodeCommand implements ICommand { constructor(node: Node) } // 记住 parent/index 以便 undo
export declare class BatchCommand implements ICommand { constructor(name: string, cmds: ICommand[]) }

// ── 画布交互（隔离 Moveable/interact/自研）──────────────────
export interface DragMoveEvent { dx: number; dy: number; committed: boolean }
export interface ResizeEvent { width: number; height: number; committed: boolean }
export interface InteractionAdapter {
  attach(els: Element[]): void;      // 在覆盖层为这些元素渲染选中框/手柄并接管指针
  detach(): void;
  isLocked: (el: Element) => boolean; // 锁定谓词：由 app 注入，适配器不自持锁定状态
  onDragMove(cb: (e: DragMoveEvent) => void): void;   // 临时移动走预览态，committed 时发 MoveCommand
  onResize(cb: (e: ResizeEvent) => void): void;
  showGuides(g: Guide[]): void;      // 对齐吸附线/等距由 core 计算，适配器只负责画

// ── 就地文本编辑（收敛 contentEditable）─────────────────────
export interface InlineTextEditor {
  start(el: Element): void;          // 加 contenteditable/data-ep-editing，聚焦，统一 Enter
  commit(): string | null;           // 取最终文本，移除标记；返回文本（null=无变化）
  cancel(): void;
  isEditing(): boolean;
}

// ── 预览沙箱（双 DOM）───────────────────────────────────────
export interface PreviewSandbox {
```

## 5. 双 iframe 隔离矩阵（照此实现，安全细节不要自行更改）

| 模式 | 容器 | `sandbox` 取值 | 脚本 | 样式隔离 | 能否访问内部 DOM |
| --- | --- | --- | --- | --- | --- |
| 编辑态 | 编辑 iframe（CanvasHost 管理） | `allow-same-origin`（**不含** `allow-scripts`） | 不执行 | 是（iframe 独立文档） | 是（`contentDocument`） |
| 预览态 | 预览 iframe（PreviewSandbox） | `srcdoc` + `allow-scripts`（**不含** `allow-same-origin`） | 执行 | 是 | 否（跨源）；extract 走桥接 `postMessage`（见下注） |

- 注（安全基线，不得自行放宽）：预览帧**不给** `allow-same-origin`，使用户脚本处于跨源沙箱、**无法访问父页与外壳 DOM / cookie**；代价是父页也不能直接读其 `contentDocument`，因此随 srcdoc 注入一段**我方内置桥接脚本**：收到父页 `postMessage('ep:extract')` 后，把 `<!DOCTYPE html>` + `document.documentElement.outerHTML` 经 `event.source.postMessage` 回传，父页校验 `event.source === 预览帧.contentWindow`（详见 T115，含 2s 超时降级）。编辑帧给 same-origin、不给 scripts，故既能直接操作 DOM 又保证脚本不运行。**T119 必须有 E2E 断言：预览脚本访问 `parent.document` / `#ep-app` 失败，且全程无编辑器发起的外联请求。**
- 编辑态写入 DOM 时脚本不执行（sandbox 无 allow-scripts 即足够），无需删除用户 `<script>`，从而导出可保留原始脚本。
- 覆盖层 `#ep-overlay-root` 位于**外壳**，通过 `getBoundingClientRect()` + iframe 偏移做坐标换算（T103 实现 `frameToOverlay()` 工具函数并单测）。

## 7. 可编辑性分级（CapabilityScanner 判定规则）

| 级别 | 判定（满足其一） | 允许操作 |
| --- | --- | --- |
| `full` | 普通 HTML 元素，非下述特殊情形 | 内部文本、样式、位移、缩放、增删子节点 |
| `inline-text` | 表单控件值、`<a>` 文本等改结构有副作用者 | 改文本/部分属性，不增删其子结构 |
| `block-only` | 第三方组件根、含复杂 SVG/canvas 容器、Shadow DOM 宿主 | 整体选中/位移/隐藏/替换，提示不可入内 |
| `non-editable` | 伪元素内容、Shadow DOM 内部、canvas 位图内部 | 不可直接编辑；只能通过其父级整体处理 |

扫描在导入后执行一次并随结构变更增量更新；UI 对非 `full` 元素给出锁定样式与原因文案（`i18n` key，如 `cap.blockOnly.tip`），**不静默失败、不报错中断**。

## 8. 质量度量与样本库（客观验收的"裁判"）

### 8.1 样本库 `qa/fixtures/`（T004 建，20–30 个，按类前缀命名）

`01-ai-landing-*.html`、`02-resume-*.html`、`03-script-carousel-*.html`（含轮播/表单脚本）、`04-external-assets-*.html`（外链图/字体）、`05-malformed-*.html`（残缺标签）、`06-complex-position-*.html`（flex/grid/绝对定位混合）、`07-svg-table-*.html`、`08-shadowdom-*.html`、`09-large-*.html`（≥15000 节点）、`10-email-*.html`、`11-poster-*.html` 等，每类 2–3 个。样本只用于测试，不含真实隐私数据。

### 8.2 指标定义（已落地 `qa/metrics/run-metrics.mjs`，happy-dom 轻量 diff；Playwright 操作级度量待 T101 后升级）

对每个样本执行固定操作脚本：导入 → 改第一个 `h1` 文本 → 改某可定位元素背景色 → 位移 (10,8) → 撤销 → 重做 → 切预览 → 导出。

- **命中率 hitRate** = 能成功完成上述全部操作且导出包含预期改动的样本数 / 总样本数。
- **无损率 losslessRate**：对"导入后不做任何编辑直接导出"的产物，用 parse5 规范化后与原始规范化结果对比，未改动节点/属性/文本的一致比例（忽略空白差异）。
- **残留数 residueCount**：导出 HTML 中匹配编辑器注入物（`data-ep-`、`class="ep-`、`ep-overlay`、`contenteditable`、编辑器注入的 `<style id="ep-`/脚本）的命中数；**必须为 0，否则导出阻断**。
- **预览一致性 previewConsistency**：预览态关键元素存在、脚本型组件（轮播/按钮）行为生效的样本比例（初期可半自动）。

命令：`npm run qa:metrics` 输出 `qa/report/metrics-latest.json`（含逐样本明细）。**每张卡 PR 必须附该报告，且 hitRate/losslessRate 不得低于合入前基线、residueCount 必须为 0。**

> **T003 落地现状**：当前脚本（T004）以 happy-dom 做规范化静态 diff，输出 `losslessRate`/`residueCount`；`hitRate` 与 `previewConsistency` 需 T101 有真实编辑能力后，由 Playwright 跑"固定操作脚本"补全。residue 当前用六条正则检测，T101 接编辑器后升级为 §8.3 的 DOM 级纯函数清理。

### 8.3 导出前清理清单（`core/serialize` 的纯函数，逐条单测）

移除：① 残留 `contenteditable` 与 `data-ep-editing`；② 任何 `data-ep-*`；③ 覆盖层 `#ep-overlay-root` 及外壳节点；④ 编辑器注入的 `<style id="ep-*">` / `<script id="ep-*">`；⑤ 仅编辑期使用的临时 class。
保留：用户原始结构、class、id（用户自己的）、内联样式中**用户操作产生的**改动、原始 `<script>`/外链。

## 9. 代码与命名规范

- TS `strict`、`noImplicitAny`；禁用 `any`（确需用 `unknown` + 收窄，并在 PR 说明）；禁 `@ts-ignore`/`eslint-disable`（经评审豁免除外）。
- 命名：文件 `kebab-case.ts`；类型/类 `PascalCase`；函数变量 `camelCase`；常量 `UPPER_SNAKE`；外壳类名 BEM `ep-块__元素--修饰`。
- 纯逻辑（命令、能力判定、序列化清理、吸附计算、度量）放 `core/` 且**必须有单元测试**；DOM 副作用集中在 adapter/app。
