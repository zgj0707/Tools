## T101 · 行走骨架：导入 → 改一处 → 预览 → 导出　🟠 / L　【咽喉，建议资深带】

- **目标**：用最薄实现贯通主链路：粘贴/上传 HTML → 在编辑 iframe 中真实渲染（脚本不跑）→ 双击改一个标题文字 → 预览 iframe 中脚本可运行 → 导出下载 HTML，导出**无编辑器残留**、未编辑部分无损。
- **依赖**：T003、T004。
- **开工前读**：`01` §1、§4（`EditorSession/HtmlIO/PreviewSandbox`）、§5 双 iframe 矩阵、§8.3 清理清单。
- **产出文件**：
  - `src/adapters/dom/DomParserIO.ts`（`implements HtmlIO`：parse 用 `DOMParser`，serialize 用 `XMLSerializer`/`outerHTML` + 清理）
  - `src/core/serialize/stripArtifacts.ts`（与 T004 `clean-rules` 同源/复用）
  - `src/app/canvas/CanvasHost.ts`（建编辑 iframe，sandbox=`allow-same-origin`，写入 doc）
  - `src/adapters/preview/IFramePreviewSandbox.ts`（`implements PreviewSandbox`：open 用 srcdoc 且 sandbox 仅 `allow-scripts`；extract 经注入桥接脚本 `postMessage` 取回 HTML，T115 完善）
  - `src/core/model/EditorSession.ts`、`SelectionModel.ts`（本卡只需单选）
  - `src/app/canvas/quickEditText.ts`（**临时**：双击 contenteditable 改字直接写 DOM，文件头注释 `// 临时实现，T104 由 InlineTextEditor + 命令替换`）
  - `src/app/App.ts`：顶部三个按钮（导入、预览、导出 HTML）+ 一个粘贴/文件输入
  - `tests/e2e/walking-skeleton.spec.ts`

- **实现步骤**：
  1. `DomParserIO.parse`：`new DOMParser().parseFromString(source,'text/html')`；收集 `warnings`（本卡可只统计 `<script>` 数量给提示）与 `externalResources`（遍历 `img[src]`、`link[href]`、`script[src]`）。
  2. CanvasHost：动态创建 `<iframe id="ep-canvas-frame" sandbox="allow-same-origin">`，把解析出的 `documentElement` 写入其 contentDocument（脚本因无 allow-scripts 不执行）；外壳另建空 `<div id="ep-overlay-root">`（本卡先空）。
  3. 监听编辑 iframe contentDocument 的 `dblclick`：命中元素为文本类（h1-h6/p/span/a/button/li 等白名单）时，`quickEditText` 临时加 `contenteditable` 就地改字，blur 后移除属性并写回 textContent（不接撤销，留 T102/T104）。
  4. 预览：点"预览"把当前编辑 doc 序列化（不含外壳）连同最小桥接脚本注入预览 iframe 的 `srcdoc`，sandbox 仅 `allow-scripts`、**不给** `allow-same-origin`（按 §5）；桥接脚本响应父页 `postMessage` 回传 outerHTML。"返回编辑"经桥接 `extract()`（2s 超时则降级为直接复用编辑 doc，不报错）；**编辑 doc 隐藏不销毁**，以保证后续撤销历史有效。
  5. 导出：`DomParserIO.serialize(doc,{stripEditorArtifacts:true})`；若 `residue.length>0` 抛 `EditorError('EP.IO.RESIDUE')` 阻断；否则触发浏览器下载 `edited.html`。
  6. 导入支持：文件 `<input type=file accept=".html,text/html">` 读取文本 + 一个"粘贴 HTML"文本框（起始页 T118 再美化，本卡能用即可）。
  7. App 边界 `try/catch`，任何异常 toast 文案走 i18n key，不白屏。

- **验收命令**：`npm run check`；`npm run e2e`（walking-skeleton）；`npm run qa:metrics`（此时 lossless 应≈100%、residue=0；hit 的"改文本"子项可启用并应通过）。
- **手动验收**：用 `qa/fixtures/03-script-carousel-*.html`：编辑态轮播不动；双击标题改字成功；预览态轮播动、按钮可点；导出文件用浏览器直开效果一致，且在导出文件中搜索 `ep-`、`contenteditable` 均 0 命中；不编辑直接导出与原文件规范化 diff 无损。
- **不在范围**：撤销（T102）、选中框/覆盖层（T103）、样式面板、拖拽、多入口打磨、URL 导入、AI。
- **停下求助**：sandbox 配置导致脚本在编辑态运行或预览态不运行；extract 无法取回 DOM；导出无法做到 residue=0。

## T102 · 命令历史与撤销/重做基座　🟢 / S

- **目标**：所有文档改动走 `ICommand` + `HistoryStack`，键盘撤销/重做正确；用命令机制替换 T101 的临时改字。
- **依赖**：T101。
- **开工前读**：`01` §4 命令/历史签名、§1 原则 5。
- **产出文件**：`src/core/commands/HistoryStack.ts`、`commands.ts`（SetText/SetStyle/SetAttribute/Move/Resize/InsertNode/RemoveNode/Batch）、`tests/unit/history.test.ts`、`tests/unit/commands.test.ts`；在 `App.ts` 注册全局快捷键。
- **实现步骤**：
  1. `HistoryStack`：内部 `stack:ICommand[]` + `pointer`；`push` 先 `execute()` 再截断 pointer 之后的重做分支并入栈；`undo/redo` 移动指针并调用；`canUndo/canRedo`；`onChange` 订阅；`clear`。
  2. 逐命令实现，构造时保存回滚所需最小信息（旧文本、受影响元素的旧 style 快照 Map、parent/index、旧属性值）；`SetStyle` 支持多元素、只改给定属性；`Move` 写/清 translate（见 T105，本卡可先实现 translate 读写工具 `applyTranslate/clearTranslate` 放 `core/`）。
  3. `BatchCommand` 原子执行/撤销（逆序 undo）。
  4. 全局快捷键：Ctrl/⌘+Z=undo；Ctrl/⌘+Shift+Z 与 Ctrl+Y=redo；触发后刷新按钮禁用态。
  5. 把 T101 `quickEditText` 的提交改为：diff 出新旧文本，不同则 `history.push(new SetTextCommand(el,next,prev))`。
- **验收命令**：`npm run test`（含：20 步交错 undo 回到初始、redo 还原、新操作截断旧 redo、Batch 整体回滚、空操作不入栈）；`npm run check`。
- **手动验收**：改多个标题后连续 Ctrl+Z 精确回退、Ctrl+Y 重做；导入新文档后历史被清空。
- **不在范围**：拖拽/缩放（只提供命令类，不接线）、历史面板 UI。
- **停下求助**：命令需要保存的状态无法从 DOM 反推；撤销导致 contenteditable 标记残留。

## T103 · 覆盖层：hover / 选中框 / 面包屑命中　🟢 / M

- **目标**：鼠标 hover 高亮、单击选中元素并在外壳覆盖层绘制选中框；底部面包屑显示路径并可选父级；覆盖层与被编辑 DOM 完全分离。
- **依赖**：T101。
- **开工前读**：`01` §1 原则 2/3、§4 `SelectionModel/InteractionAdapter`、§5 坐标换算。
- **产出文件**：`src/app/canvas/OverlayLayer.ts`、`src/app/canvas/geom.ts`（`frameToOverlay`、`rectOf` 纯函数 + 单测）、`src/core/model/SelectionModel.ts`（补全）、`src/app/statusbar/Breadcrumb.ts`、`tests/unit/geom.test.ts`、`tests/e2e/selection.spec.ts`。
- **实现步骤**：
  1. 在编辑 iframe contentDocument 上监听 `pointermove/pointerdown`（同源可访问）；`pointerdown` 用 `e.target` 命中元素，更新 SelectionModel；hover 用一个独立高亮框跟随。
  2. OverlayLayer 在 `#ep-overlay-root` 内画：hover 框（浅色）、选中框（主色，本卡只画矩形，手柄留 T106）。
  3. `geom.frameToOverlay(rect, frameRect, scroll)` 把被选元素 `getBoundingClientRect()` 加上 iframe 在外壳中的偏移与滚动，得到覆盖层坐标；纯函数并单测。
  4. 在 `scroll/resize/窗口 resize/selection 变化/` 后用 `requestAnimationFrame` 重定位；元素被删除时清空失效选中。
  5. Breadcrumb：自选中元素向上取 `tag名.id.class` 链（最多 8 级），点击某级调用 `selection.parentOf` 逐级选中；显示在状态栏。
  6. 点击编辑文档空白处清空选择。
- **验收命令**：`npm run test`（geom 坐标/层级用例）；`npm run e2e`（hover 高亮、点选、面包屑选父级、滚动后选中框仍贴合）。
- **手动验收**：在 06-complex-position 样本上，选中框准确贴合嵌套元素；缩放浏览器窗口后位置正确；检查导出 HTML 中无 `ep-overlay`/覆盖层节点。
- **不在范围**：多选（T113）、8 向手柄与拖拽（T105/T106）、图层树（T112）。
- **停下求助**：iframe 内事件无法监听；覆盖层与 iframe 存在 z-index/坐标对不齐且无法修正。

## T104 · 双击就地改字（contentEditable 收敛）　🟢 / M

- **目标**：用正式 `InlineTextEditor` 替换 T101 临时改字：统一 Enter 行为、Esc 取消、blur 提交、只在编辑期临时加标记、提交产生可撤销命令、粘贴不引入脏标签。
- **依赖**：T102、T103。
- **开工前读**：`01` §4 `InlineTextEditor`、PRD 6.2、§6 常量 `EDITING_ATTR`。
- **产出文件**：`src/adapters/inline/ContentEditableInlineEditor.ts`、`src/core/commands/`（复用 SetTextCommand）、`tests/unit/inlineEditor.test.ts`（happy-dom）、`tests/e2e/inline-edit.spec.ts`；删除 `quickEditText.ts`。
- **实现步骤**：
  1. `start(el)`：校验 Capability（文本类且非 block-only）；存原始文本；加 `contenteditable="true"` 与 `data-ep-editing`；聚焦并把光标放到点击处/末尾。
  2. `keydown`：Enter 阻止默认，统一插入换行（块级元素用 `insertLineBreak`，不在文档里制造新 `<div>`）；Esc=取消并还原；Tab=退出编辑到下一个可选元素（可简化为 blur）。
  3. `paste`：`preventDefault`，以 `insertText` 插入纯文本（富文本净化在 T119 复核）。
  4. `blur`=commit：移除两个临时标记；取 `textContent`，与原值不同则 `history.push(new SetTextCommand(...))`，相同不入栈。
  5. `cancel()`：还原原文本并移除标记，不入栈。
  6. 同一时刻只允许一个元素处于编辑态；进入拖拽（T105）前自动 commit。
- **验收命令**：`npm run test`（Enter 不产生新 `<div>`、Esc 还原、仅变化才入栈、提交后无 contenteditable/data-ep-editing 残留）；`npm run e2e`（双击改字→撤销→恢复）；`qa:metrics` residue=0。
- **手动验收**：在不同浏览器内核（至少 Chromium）双击段落、链接、按钮、列表项均可改；粘贴一段带 Word 样式的文字，结果为纯文本；导出无脏标签。
- **不在范围**：富文本加粗/列表（由样式面板 T108 处理）、Tiptap/Lexical 集成（除非 T003 已选定，按适配器实现）。
- **停下求助**：Enter 在不同元素产生不一致且无法统一；contenteditable 残留无法在提交时清干净。

## T105 · 拖拽微移（transform + 死区 + 边缘判定）　🟠 / M

- **目标**：元素可在画布上自由微移，位移只用 `transform:translate`、不脱离文档流；具备 5px 死区、"边缘拖/内部选字"判定、rAF、Shift 轴向约束、一键重置；操作产生可撤销命令。
- **依赖**：T102、T103。
- **开工前读**：`01` §1 原则 6、§4 `InteractionAdapter/DragMoveEvent/MoveCommand`、§6 常量、PRD 6.7。
- **产出文件**：`src/adapters/interaction/SelfInteractionAdapter.ts`（若 T003 选定 Moveable/interact，则在对应适配器内实现，端口不变）、`src/core/interaction/dragIntent.ts`（`shouldStartDrag`、死区状态机，纯函数 + 单测）、`src/core/interaction/transform.ts`（translate 读写/累加/清除，纯函数 + 单测）、`tests/unit/dragIntent.test.ts`、`tests/e2e/drag.spec.ts`；Ribbon 加"重置位移"按钮。
- **实现步骤**：
  1. `shouldStartDrag(el, localX, localY, rect)`：距边缘 ≤`EDGE_HANDLE_PX` 返回 true；内部且元素有文本返回 false（让位于文字选择/编辑）；无文本元素内部可拖。纯函数单测覆盖四角/边缘/内部文本。
  2. pointerdown 进入 `pending`；移动 `<DRAG_DEAD_ZONE_PX` 不移动元素（仅光标变 grabbing）；≥5px 进入 `drag`。
  3. 拖拽中在 `requestAnimationFrame` 内用 `transform.ts` 写**临时** translate（在原值上累加 dx/dy，保留 scale/rotate 分量）；按住 Shift 约束为水平或垂直单轴（按较大分量）。
  4. pointerup：若发生位移，`history.push(new MoveCommand(targets,totalDx,totalDy))`；未超死区按点击处理（交给选中）。
  5. 多选元素随 T113 支持，本卡单元素即可，但接口接收 `targets:Element[]`。
  6. "重置位移"：对选中元素发命令清除其 translate 分量（可复用 SetStyle 清 transform 中的 translate）。
  7. 进入拖拽前若 InlineTextEditor 正在编辑，先 commit。
- **验收命令**：`npm run test`（死区、边缘判定、translate 累加/清除、Shift 约束）；`npm run e2e`（拖卡片产生 transform、撤销归零、重置回文档流、改窄窗口元素仍参与流式布局不重叠）。
- **手动验收**：点选时手抖动元素不跳；内部文字可正常选中、边缘可拖；导出文件中位移体现为 `transform:translate(...)` 而非 `position:absolute`（grep 断言）。
- **不在范围**：缩放（T106）、对齐吸附（T107）、多选（T113）。
- **停下求助**：第三方交互库强制使用 absolute 定位（与原则冲突，需回到 T003 决策）；transform 累加破坏原有 scale/rotate。

## T106 · 8 向缩放手柄　🟢 / M

- **目标**：选中框显示 8 个手柄，拖拽改变元素宽高（写 width/height），Shift 等比，最小尺寸保护，可撤销。
- **依赖**：T102、T103。
- **开工前读**：`01` §4 `ResizeEvent/ResizeCommand`、§6 `MIN_BOX_PX`。
- **产出文件**：`OverlayLayer` 增 `renderHandles`、`src/core/interaction/resize.ts`（按手柄方向计算新宽高的纯函数 + 单测）、`ResizeCommand` 接线、`tests/unit/resize.test.ts`、`tests/e2e/resize.spec.ts`。
- **实现步骤**：
  1. 在选中框四边+四角渲染 8 个手柄（覆盖层 div），记录方向 n/s/e/w/ne/nw/se/sw。
  2. pointerdown 手柄记录起始 rect 与指针位置；rAF 中 `resize.compute(方向,startRect,dx,dy,shiftKey)` 得新宽高。
  3. **P0 简化规则（照此实现，不自行加复杂锚点补偿）**：水平方向手柄改 width（左锚），垂直改 height（上锚），角手柄同时改；结果钳制 ≥`MIN_BOX_PX`；Shift 在角手柄上等比（按较大变化比例）。
  4. 临时预览写 `element.style.width/height`；pointerup 发 `ResizeCommand`。
  5. 对 `<img>` 等固有比例元素，Shift 默认按比例；普通元素不强制。
- **验收命令**：`npm run test`（8 方向符号、最小值钳制、Shift 等比）；`npm run e2e`（拖右下放大、撤销还原、小于最小值被钳制）。
- **手动验收**：手柄不与拖拽冲突（手柄上 pointerdown 不触发移动）；缩放中不出选中框抖动。
- **不在范围**：旋转、对侧锚点固定的高级缩放、flex 子项拉伸语义调整。
- **停下求助**：目标元素宽高受 box-sizing/布局影响导致数值与视觉不一致且无法统一。

## T107 · 对齐吸附与等距提示　🟢 / M

- **目标**：拖拽/缩放时自动与兄弟元素边/中线吸附并显示参考线；≥3 个同类元素时提示等距。
- **依赖**：T105、T106。
- **开工前读**：`01` §4 `Guide/InteractionAdapter.showGuides`、§6 `SNAP_THRESHOLD_PX/EQUAL_SPACE_PX`、PRD 6.7。
- **产出文件**：`src/core/interaction/snap.ts`（`computeEdgeGuides`、`computeEqualSpacing` 纯函数 + 单测）、OverlayLayer 画线、接入 T105/T106 的 rAF 循环、`tests/unit/snap.test.ts`、`tests/e2e/snap.spec.ts`。
- **实现步骤**：
  1. `computeEdgeGuides(dragRect, siblingRects)`：比较左/右/水平中心、上/下/垂直中心，差 ≤`SNAP_THRESHOLD_PX` 时返回吸附偏移与 `Guide`（含位置与方向）。
  2. 应用吸附：把偏移钳到指针位移上（元素对齐而非仅画线）。
  3. `computeEqualSpacing`：同层级 ≥3 个元素时，若相邻间距在 `EQUAL_SPACE_PX` 内相等，返回蓝色双箭头+间距数值的 Guide。
  4. 拖拽结束清空 guides；guides 全部画在覆盖层。
  5. 性能：只遍历可见兄弟节点，计算放 rAF。
- **验收命令**：`npm run test`（6 条对齐线、阈值边界、等距三元素正例/二元素反例）；`npm run e2e`（拖第二张卡片接近与第一张对齐时出现参考线并吸附）。
- **手动验收**：参考线不闪烁到影响操作；无元素时不画线。
- **不在范围**：智能分布排版、网格系统、自定义参考线。
- **停下求助**：吸附导致元素"跳动"无法稳定；跨容器对齐计算口径不清。
