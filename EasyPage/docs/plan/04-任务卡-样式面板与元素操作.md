# 04 · 任务卡 · Stage 2（样式面板与元素操作）

> 统一字段同前。本阶段所有样式改动都通过 `SetStyleCommand` / `SetAttributeCommand` 写**内联 style**（D5：P0 内联），可撤销；面板控件读取 `getComputedStyle` 回填。

## T108 · 样式面板骨架 + 文字属性　🟢 / M

- **目标**：右侧面板随选中元素双向同步；可改字体、字号、字重、颜色、背景色、对齐、行高、字距、列表、链接，改动即时可见、可撤销。
- **依赖**：T103、T102。
- **开工前读**：`01` §4 `SetStyleCommand/SetAttributeCommand`、§9 文案规范。
- **产出文件**：`src/app/panels/style/StylePanel.ts`、`fields.ts`（控件工厂）、`src/core/style/textProps.ts`（属性名映射纯函数 + 单测）、`src/app/i18n/zh-CN.ts` 补 key、`tests/unit/textProps.test.ts`、`tests/e2e/style-text.spec.ts`。
- **实现步骤**：
  1. StylePanel 订阅 `selection.onChange`：单选读 `getComputedStyle(el)` 回填；多选读取共有值，无共有值显示"多选/混合"占位。
  2. 控件与 CSS 属性映射（`textProps.ts`）：font-family、font-size(px)、font-weight(400/500/600/700)、color、background-color、text-align、line-height、letter-spacing；列表：对最近块容器切换 `<ul>/<ol>`（P0 仅"转为列表/取消列表"两动作）；链接：对 `<a>` 或选中文本设置/清除 `href`（SetAttribute）。
  3. 字体列表用固定白名单（系统字体栈，不加载网络字体），常量集中定义。
  4. **提交规约（避免历史栈爆炸）**：控件交互中（拖动滑条/连续输入）临时写内联预览；在 `change` 提交或 `blur/Enter` 时，用交互开始时记录的初始值一次性 `history.push(new SetStyleCommand(els, changedProps, prevSnapshot))`；无变化不入栈。
  5. 非 `full` 能力元素禁用不适用控件并给提示。
- **验收命令**：`npm run test`（映射、混合值、仅变化入栈）；`npm run e2e`（选中标题改字号/颜色/对齐→导出保留→撤销还原）；`qa:metrics` 不劣化。
- **手动验收**：连续拖字号滑条只产生一次可撤销记录；多选改色作用于全部。
- **不在范围**：盒模型/外观（T109）、网络字体、class 模式（P1）。
- **停下求助**：getComputedStyle 返回值单位/格式无法稳定回填到控件；列表切换破坏原有结构。

## T109 · 盒模型与外观属性　🟢 / M

- **目标**：可调宽高、margin/padding、边框、圆角、阴影、透明度。
- **依赖**：T108。
- **产出文件**：`StylePanel` 增 `BoxModelSection.ts`、`DecorationSection.ts`、`src/core/style/boxProps.ts`（+单测）、`tests/e2e/style-box.spec.ts`。
- **实现步骤**：
  1. 盒模型控件（仿 DevTools 方框）：width/height、margin/padding 四向（px，数字步进），写内联；展示当前计算值。
  2. 外观：background-color（复用）、border-width/style/color（简写拆写，避免覆盖问题）、border-radius（四角，P0 单值 + 可选分别）、box-shadow（x/y/blur/spread/color 五输入 + 无阴影开关）、opacity（0–1）。
  3. 沿用 T108 提交规约（交互结束一条命令）；数值为 0/空时正确清除该属性而非写 "0px" 冗余（按属性区分，如 border 关闭要移除）。
  4. 纯函数负责"控件值 ↔ CSS 字符串"互转并单测（尤其 box-shadow/border 解析）。
- **验收命令**：`npm run test`（互转、清除冗余、四向）；`npm run e2e`（给卡片加圆角阴影、调 padding，导出保留，撤销还原）。
- **手动验收**：改 margin 引发布局变化符合预期；连调只产生一条历史。
- **不在范围**：渐变背景、背景图、filter 动效、flex/grid 子项属性。
- **停下求助**：简写属性拆写导致样式闪烁或覆盖用户原有边框。

## T110 · 格式刷　🟢 / S

- **目标**：一键复制源元素计算样式到目标元素（内联），支持连续涂抹，整体可一次撤销。
- **依赖**：T109。
- **产出文件**：`src/app/ribbon/FormatPainter.ts`、`src/core/style/formatPaint.ts`（`collectStyles`/`buildStyleProps` 纯函数 + 单测）、`tests/unit/formatPaint.test.ts`、`tests/e2e/format-painter.spec.ts`。
- **实现步骤**：
  1. `collectStyles(getComputedStyle(source))` 取固定白名单（PRD 6.7）：color、backgroundColor、fontSize、fontWeight、fontFamily、fontStyle、textDecoration、textAlign、lineHeight、letterSpacing、borderRadius、border、boxShadow、opacity、padding、textShadow。
  2. 单击格式刷进入单次模式（外壳 `cursor:copy`），下一次点目标即涂抹并退出；双击进入连续模式（可点多个目标），Esc 或再点按钮退出。
  3. 每次涂抹对目标 `history.push(new SetStyleCommand(...))`；连续模式退出时把本次连续涂抹合并为一次可撤销（用进入连续模式时的快照做一个 Batch 或等效聚合）。
  4. 目标非 full 能力时给提示、不涂抹。
- **验收命令**：`npm run test`（白名单完整、不复制布局定位类属性、聚合撤销）；`npm run e2e`（A 刷到 B/C 视觉一致，一次 Ctrl+Z 全部还原）。
- **手动验收**：格式刷不复制 margin/定位/transform（只刷视觉样式，避免意外移位；如评审要求含 padding 已在白名单）。
- **不在范围**：跨页面刷样式、刷结构。
- **停下求助**：getComputedStyle 的复合值（border/shadow）写入目标后视觉不等效。

## T111 · 插入元素　🟢 / M

- **目标**：从左面板插入文本/标题/按钮/图片/形状分割线/容器/表格，插入即选中、可撤销。
- **依赖**：T102、T103。
- **产出文件**：`src/app/panels/elements/ElementsPanel.ts`、`src/core/elements/factory.ts`（元素默认样式/结构，纯函数 + 单测）、`src/app/panels/elements/ImagePicker.ts`、`tests/unit/factory.test.ts`、`tests/e2e/insert.spec.ts`。
- **实现步骤**：
  1. `factory.create(kind)` 用编辑文档 `doc.createElement` 生成：h1/h2/h3、p、button（带默认内联样式常量）、img、div 形状、hr、div/section 容器、table（行列选择，2×2 默认，带边框样式常量）。默认样式集中在 `factory.ts` 常量，不硬编码于 UI。
  2. 插入位置规则：选中容器类元素→插到其内部末尾；选中叶子/文本→插到其后；无选中→插到 body 末尾。用 `InsertNodeCommand`。
  3. 图片三来源：URL（提示输入）、占位图（内置 SVG data URI）、本地上传（用 `URL.createObjectURL` 本地预览；**P0 不做 base64 内嵌，列 P1**，导出时该图进入"未内嵌资源清单"提示，见 T116）。
  4. 插入后选中新元素；连续插入同类不重复弹 URL 框（图片除外）。
  5. 删除元素走 `RemoveNodeCommand`（记住 parent/index 供撤销）。
- **验收命令**：`npm run test`（各 kind 结构、插入位置三规则）；`npm run e2e`（插入按钮/表格/图片→撤销移除→重做恢复）。
- **手动验收**：插入元素出现在合理位置且不破坏现有布局；本地上传图片不发起任何网络请求。
- **不在范围**：视频/音频/表单控件、组件模板库、图片 base64、区块嵌套的拖拽编排。
- **停下求助**：在表格/列表等结构中插入位置规则出现歧义；objectURL 在导出后失效的处理与 T116 对不上。

## T112 · 图层面板 + 锁定 / 隐藏 / 层级　🟢 / M

- **目标**：左面板图层树与画布双向联动；可显隐、锁定、同父重排层级；锁定不污染导出。
- **依赖**：T103。
- **产出文件**：`src/app/panels/layers/LayersPanel.ts`、`src/core/model/LockState.ts`（WeakSet，内存态）、`src/core/commands/ReorderNodeCommand.ts`、`tests/unit/reorder.test.ts`、`tests/e2e/layers.spec.ts`。
- **实现步骤**：
  1. 从 `doc.body` 构建树（过滤 `script/style/meta/link/title` 与编辑器节点）；每层显示标签 + 识别名（id，否则首个 class，否则文本前 12 字）；默认折叠深层（>4 级）。
  2. 树项 hover/点击与画布选中双向联动；树在结构变更（命令执行后）刷新。
  3. 眼睛图标：切换内联 `display:none`（真实改动、可导出、可撤销，走 SetStyleCommand）。
  4. 锁图标：写入内存 `LockState`（**不写被编辑 DOM 属性**）；锁定元素在画布显示锁遮罩、`cursor:not-allowed`，不可拖拽/缩放/入内编辑，但可在图层解锁；导出不含任何锁定标记（单测断言）。
  5. 层级：上移/下移/置顶/置底，仅在**同一父节点内**重排（`ReorderNodeCommand`，记原 index）；跨容器拖拽层级不做。
- **验收命令**：`npm run test`（重排 index、锁定不进 DOM/导出）；`npm run e2e`（隐藏后不可见且导出为 display:none；锁定后拖不动；置顶生效并可撤销）。
- **手动验收**：大样本（09-large）图层树不卡（可按需懒渲染）；锁定/隐藏状态在撤销后正确回退。
- **不在范围**：图层跨容器拖拽、图层分组重命名、锁定状态持久化到文件（P0 仅会话内）。
- **停下求助**：命令后树刷新出现选中错位；隐藏的 display 与用户原有 display 冲突无法恢复。

## T113 · 多选 + 对齐 / 分布　🟢 / M

- **目标**：框选与 Shift 点选多选；多元素左/右/居中/顶/底对齐与水平/垂直等距分布，结果可一次撤销。
- **依赖**：T107、T103。
- **产出文件**：`src/app/canvas/Marquee.ts`（框选矩形）、`src/core/layout/alignment.ts`（纯函数 + 单测）、`Ribbon` 对齐分布按钮组、`tests/unit/alignment.test.ts`、`tests/e2e/multi-select.spec.ts`。
- **实现步骤**：
  1. 在画布空白处 pointerdown 拖出 marquee 矩形（覆盖层），相交元素加入多选；Shift+点击 toggle；Esc/点空白清空。
  2. `alignment.compute(els, type)` 基于各元素当前 `getBoundingClientRect` 与父级坐标，算出每个元素需要的 dx/dy（**用 translate 实现，不改 position、不改 DOM 顺序**）。
  3. 支持：左/右/水平居中、顶/底/垂直居中；水平/垂直等距分布（保持首尾位置，均分中间）。
  4. 一次操作发一个 `Batch(MoveCommand[])`；多选样式编辑沿用 T108。
- **验收命令**：`npm run test`（六种对齐坐标、等距分布、首尾固定）；`npm run e2e`（框选三卡片→等距分布→一次撤销归位）。
- **手动验收**：对齐用 transform 实现，导出 grep 无新增 position:absolute；缩放窗口后分布不产生重叠孤岛。
- **不在范围**：智能网格、自动布局容器、跨 iframe/跨容器对齐。
- **停下求助**：translate 对齐与元素已有 transform 叠加错误；分布在不同父容器元素间口径不清（应限定同父，跨父给提示）。

## T114b · 就地编辑：选区富文本（加粗/斜体/下划线）与插入链接　🟠 / M

- **目标**：双击进入就地编辑（contenteditable）后，对**选中的一段文字**做加粗/斜体/下划线、插入超链接；只支持最小安全范围；全部可一次撤销；导出保留为干净的语义标签、无编辑器残留。
- **依赖**：T104（InlineTextEditor）、T102（HistoryStack/命令）、T114（keymap/焦点守卫）。
- **背景约束（必须遵守）**：T114 已把编辑态 Ctrl+B/I/U 临时拦截并 toast「后续版本支持」，本卡把它替换为真实能力。**禁止使用 `document.execCommand`**（产生不可控标签、绕过我们的 HistoryStack、撤销行为不一致）。一律用 Range + 显式包裹/解包 + 入命令历史实现。
- **产出文件**：
  - `src/core/inline/wrapInline.ts`（纯逻辑，不依赖 app/DOM 事件：选区是否合法、包裹/解包、URL 规范化与协议白名单）
  - `src/core/commands/inlineCommands.ts`（`InlineWrapCommand`，可逆；或在现有 commands.ts 内新增并保持同风格）
  - `src/app/canvas/InlineSelection.ts`（在编辑文档内捕获/克隆当前活动 Range，处理失焦）
  - `src/app/panels/ribbon/LinkPopover.ts`（外壳 `ep-` URL 输入条；不进被编辑文档）
  - 改 `src/app/keymap.ts`（新增 action `link` = Ctrl/⌘+K）、`src/app/App.ts`（编辑态 B/I/U 与 Ctrl+K 分流接线，替换 richLater 拦截）
  - `tests/unit/wrapInline.test.ts`、`tests/e2e/inline-format.spec.ts`
- **实现步骤**：
  1. **合法选区判定（纯函数）**：仅当存在非折叠选区，且 `range.startContainer === range.endContainer` 且为**文本节点**（nodeType 3），选区文本 `trim()` 非空，才允许包裹；跨元素、跨文本节点、选区包含元素节点、折叠选区一律返回"不支持"。
  2. **包裹（纯逻辑 + DOM 操作分离）**：对单文本节点内的部分文本，先按 startOffset/endOffset 把文本节点切分为「前 / 选中 / 后」三段，用语义标签包裹"选中"段：加粗 `<strong>`、斜体 `<em>`、下划线 `<u>`；链接用 `<a href>` 包裹。包裹后不保留多余空文本节点。**切换（toggle）**：若选中部分已被同一种标签元素完整包裹（如选区就在单个 `<strong>` 内），则解包（用其文本子节点替换该标签并与相邻文本节点合并）；否则执行包裹。
  3. **链接**：Ctrl/⌘+K（编辑态）或编辑态工具栏"链接"按钮触发；在触发瞬间（弹层打开、contenteditable 失焦**之前**）用 `getSelection().getRangeAt(0).cloneRange()` 保存静态 Range（同时记录 startContainer 与 offsets 兜底）。弹外壳 `ep-` 输入条让用户填 URL：
     - URL 规范化：去掉首尾空格；若不含协议且看起来是域名（含点、无空格），自动补 `https://`；`#锚点`、`/相对路径`、`mailto:` 原样保留。
     - **协议白名单（安全，必做）**：只允许 `http:`、`https:`、`mailto:`、`ftp:` 以及以 `#`/`/` 开头的相对地址；`javascript:`、`data:`、`vbscript:` 及任何其他协议一律拒绝并 toast，不插入。空 URL 取消操作、不改 DOM。
     - 生成 `<a href="规范化URL">`（P0 不强制 target/rel，但不得写入内联脚本）。
  4. **可逆命令**：新增 `InlineWrapCommand`，`apply()` 执行包裹/解包，`undo()` 必须把 DOM 与文本精确还原到操作前（解包时移除标签、还原并合并文本节点；包裹的逆操作是还原切分）。每次操作 push 一条命令，Ctrl+Z 一次还原、Ctrl+Y 重做。命令需持有容器父节点、标签类型/属性、文本与偏移，不依赖操作后仍存在的全局 Selection。
  5. **接线**：编辑态（InlineTextEditor.isEditing()）按 Ctrl+B/I/U 走选区包裹命令；新增 Ctrl+K 走链接流程；非编辑态维持 T114 的"整元素"加粗/斜体/下划线不变。工具栏在编辑态可出现加粗/斜体/下划线/链接按钮（按钮 mousedown 必须 `preventDefault()` 以保持 contenteditable 焦点不丢）。
  6. **失焦处理**：链接输入条获得焦点会使编辑文档失焦，因此第 3 步必须在失焦前克隆 Range；命令作用于该克隆 Range 所指向的节点（节点仍在文档中，Range 有效）。若保存的 Range 在打开弹层后已失效（节点被移除等），toast 提示并放弃，不报错、不改 DOM。
- **验收命令**：
  - `npm run test`（wrapInline 纯函数）：合法/折叠/跨节点/跨元素选区判定；部分文本包裹后三段文本与原文逐字符一致、标签正确；包裹→解包还原；toggle 行为；URL 补 `https://`、相对/锚点/mailto 保留、`javascript:alert(1)` 与 `data:text/html...` 被拒。
  - `npm run e2e`（inline-format，用 `evaluate` 在 contenteditable 内构造 Selection/Range 再 `dispatchEvent` 合成 Ctrl+B/I/U 与 Ctrl+K，不依赖真实鼠标）：选中同一元素内部分文字→Ctrl+B 出现 `<strong>` 且整段文本无增减→导出 HTML 含 `<strong>`、无 `ep-`/`contenteditable`/`data-ep-editing` 残留→Ctrl+Z 后无 `<strong>` 且文本还原；Ctrl+K 输入 `example.com` 生成 `href="https://example.com"` 的 `<a>`，输入 `javascript:alert(1)` 被拒且不产生 `<a>`；构造跨两个元素的选区→Ctrl+B 出现"不支持"提示且 DOM 不变。
  - `npm run check` 全绿；`npm run qa:metrics` 维持 losslessRate=1、residueCount=0。
- **手动验收**：双击段落→选几个字→加粗/斜体/下划线视觉生效且可连续撤销；链接弹层打开时编辑选区不丢；导出文件在浏览器打开，加粗与链接正常、点击链接不执行脚本。
- **不在范围（P0 后置）**：选区级字体/字号/颜色/高亮、列表、对齐、图片与表格内富文本、编辑/清除已有链接（本卡只做新建链接）、跨多元素的选区格式化、`execCommand` 方案、协同/评论。
- **停下求助**：切分在边界节点类型上抛异常且无法用 extract+insert 稳定实现；克隆 Range 失焦后失效且 offsets 兜底也无法定位；undo 无法把文本节点还原/合并到与操作前一致——停下上报，不要放宽"单文本节点"限制去硬做跨节点。
